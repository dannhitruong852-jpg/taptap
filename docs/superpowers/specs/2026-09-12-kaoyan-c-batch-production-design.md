# 考研英语真题 C 模式全量批处理系统设计

日期：2026-09-12
状态：已由用户在对话中确认，进入实施
目标项目：`kaoyan-reader-v1`

## 1. 总目标

把当前 2002 Text 1 单篇样片升级为可批量生产多年真题的静态学习网站。用户不需要手动把 PDF 导入网站，也不需要逐篇试听确认。源 PDF 在离线生产阶段处理，最终网站只负责选择年份/题型/文章、显示中英对照与词汇等级、播放预生成音频。

批处理采用 fail-soft：单篇或单片段失败不得阻塞其他年份；可自动修复的直接重试，不能自动修复的隔离为待修复项，最后统一收尾。

## 2. 内容范围

对已提供的年度真题 PDF 批量处理；`大纲词汇背诵宝典（英语二）.pdf` 只用于词汇难度辅助，不作为试卷年份。

每张试卷只进入网站以下英文正文：

1. Section I / Use of English：只保留完型填空文章正文；选项仅可在生产阶段作为还原空格的辅助数据，不进入网站。
2. Section II / Reading Comprehension Part A：只保留各 Text 的文章正文；题干与 A/B/C/D 选项不进入网站。
3. Section II Part B / 新题型：只保留用于作答的英文文章正文；匹配项、题目、备选项不进入网站。
4. Translation：只保留要求翻译的英文原文；题目说明不进入网站。
5. Writing：全部忽略，包括小作文、大作文、图表、范文。

旧年份题型名称与英语（二）现行名称不完全一致时，以“正文功能”映射到 `cloze`、`reading`、`part_b`、`translation`，不把题目选项混进正文。

## 3. C 总纲：理解导向的美式日常交流式朗读

C 模式是所有年份、所有文章的最高层默认规则。

1. **理解优先于表演。** 声音的首要目标是帮助听者理解重点、逻辑、结构、态度与含义。
2. **每一句都有自然语气。** 旁白不等于平读。`neutral` 表示没有特殊情绪，但仍有自然重音、停顿、轻重、句尾走势和信息焦点。
3. **角色稳定，韵律持续变化。** 同一篇文章尽量保持一个主讲人；语气变化主要由同一演员完成。
4. **先理解再导演。** 固定顺序：语义理解 -> 话语功能 -> 信息焦点 -> 逻辑关系 -> 韵律曲线 -> 情绪/强度 -> 速度/停顿/重音。
5. **每句有小起伏，连续 2–3 句必须出现可感知的微反差。** 任意连续 3 句不能全部处于低变化状态；没有天然强点时，选择其中信息价值最高的一句形成微反差。
6. **强表演必须有文本依据。** 对白、强转折、讽刺、笑点、冲突、明显评价等才允许明显加强。
7. **允许句内韵律变化与必要的句内换声。** 长句不能只贴一个情绪标签；转折、并列、递进、动作链、引语等可形成句内曲线。
8. **速度采用美国人正常交谈的自然速度。** 不采用教学慢速；复杂逻辑和强调处可局部稍慢，简单/动作/轻松内容可局部稍快。

总纲压缩为：像一个真正读懂文章的美国人面对面把内容讲给学习者听——不是念文章，而是在传递思想。

## 4. 演员规则

保留现有 15 个演员槽位与美音为主、少量英音的演员体系。具体演员由自动导演自行分配，不再要求用户逐篇确认。

- 演员系统回答“谁在说”；C 总纲回答“应该怎么说”。
- 主演员按文章人格选择，而不是按单句情绪选择。
- **角色定位是优先适配领域，不是使用权限。** 任何演员只要与文章人格、题材和表达要求匹配，都可以承担整篇主讲；11、12、13 不因“角色型”定位而被限制为只能客串。
- **选角优先级一：文章匹配度第一。** 先判断文章主题、叙事人格、受众关系、情绪基调与话语功能，选择最适合传递该篇内容的演员；不得为了轮换或平均出场而牺牲文章匹配度。
- **选角优先级二：C 总纲适配第二。** 候选演员必须能够在该文章中保持理解导向、自然、稳定和有文本依据的表达；若某演员的角色气质会导致过度表演、语气失真或削弱信息传递，则即使其朗读量偏低也不得优先使用。
- **选角优先级三：负载均衡第三。** 只有当两个或多个演员在文章匹配度与 C 总纲适配度上都达到可接受水平且差距不显著时，才优先选择累计朗读词数或音频时长较少的演员。负载均衡是同等适配候选之间的决胜规则，不得凌驾于作品质量之上。
- 只有真实说话者变化、明确对白或角色化引用才优先换演员。
- 普通文章原则上 1–4 位演员；不靠频繁换演员制造丰富感。
- 同一角色在同一篇文章中必须固定 `actor_id`。
- 真人姓名只作为气质锚点，不作为可识别真人克隆目标；正式参考声纹必须使用许可明确、可稳定保存和处理的语料。

## 5. 内容结构

标准层级：

`年份 -> 题型 -> 文章 -> 段落 -> 句子 -> 句内片段`

文章至少包含：

- `year`
- `section_type`: `cloze | reading | part_b | translation`
- `article_id`
- `source_sha256`
- `accent`
- `primary_actor_id`
- `article_context`
- `sentences[]`

句子至少包含：

- `id`
- `en`
- `zh`
- `vocab[]`
- `discourse_function`
- `prosody_focus[]`
- `contrast_level`: `low | micro | strong`
- `segments[]`

片段至少包含：

- `id`
- `text`
- `speaker_role`
- `actor_id`
- `emotion`
- `intensity`: `0 | 1 | 2`
- `rate`
- `pause_before_ms`
- `pause_after_ms`
- `audio_path`
- `generation_fingerprint`
- `qa_status`

## 6. 翻译标准

翻译按“信、达、雅”三层同时执行：

- 信：不得漏译、增译或改变原意；逻辑关系、限定关系和语气必须保留。
- 达：中文必须自然、通顺，避免英语句法生搬硬套。
- 雅：在不牺牲准确性的前提下，句式顺畅、简洁、适合连续阅读。

生产阶段采用句级对齐，保留英文原句与中文译句的一一对应。机器批量初译之后必须经过第二轮批量自审，重点检查漏译、主从关系、否定、比较、代词指代、术语与不自然直译。内容校验不通过的文章不得标记为最终通过。

## 7. 词汇 1–9 级

所有英文词可被统一难度函数分级为 1–9；网站重点标记 6–9 级，其中 6 级及以上加粗。

分级应保持跨年份稳定，不按文章主观临时调整。难度函数优先结合：考研词汇宝典中的真题频次/零频/超纲信息、通用英语词频、词形复杂度与语境义；无法可靠识别的专名不强行当作难词。

## 8. 批量生产流水线

流水线拆为可并行阶段：

1. `extract`：从 PDF 文本中识别并提取目标正文，剔除题干、选项、作文和说明。
2. `normalize`：修复 PDF 换行、连字符、异常空格、OCR 轻微字符问题，并保留原始来源哈希。
3. `enrich`：句子切分、信达雅中译、词汇分级、文章人格判断、15 演员选角、C 总纲导演参数。
4. `content_qa`：检查正文完整性、句子覆盖、结构字段、C 总纲密度规则与翻译结构异常。
5. `voice`：Chatterbox 按片段并行生成；模型/依赖/参考声纹尽量缓存。
6. `audio_qa`：检查文件存在、时长、截断、静音、音量、速度；可用时增加本地 ASR 与说话人一致性检查。
7. `publish`：只发布通过或明确为候选但可用的资产；失败项进入报告，不阻塞其他年份。
8. `deploy`：渐进式写入静态网站，同一网址持续扩充年份与文章。

## 9. 并发与容错

- 年份/文章互相独立，可矩阵并行。
- 音频生成再按文章或片段分片并行。
- 单个任务失败最多自动重试若干次，使用不同 deterministic retry seed；仍失败则记录到 `reports/failures.json`。
- 已通过资产按 fingerprint 缓存，重复运行不重算。
- 不因一个年份失败停止其他年份。
- 最终收尾阶段集中重跑失败项。

## 10. 成本与运行方式

- 网站运行时不调用 TTS、翻译或 AI API。
- TTS 继续使用 Chatterbox 离线/Actions 预生成，不使用 Google TTS 或商业按字数/分钟收费 TTS。
- 尽量使用公开许可模型和 GitHub Actions 计算；若未来需要新增会产生明确费用的外部服务，才属于需要重新决策的架构变化。
- 用户不需要安装模型、不需要上传 PDF 到网页、不需要逐篇确认。

## 11. 网站交互

同一个 GitHub Pages 网址提供：

- 年份选择；
- 题型选择；
- 文章选择；
- 英文句子 + 中文译文；
- 6–9 级重点词汇加粗/标记；
- 播放/暂停、上一句/下一句、重播；
- 当前句高亮；
- 0.85x / 1x / 1.15x 用户速度；
- 下滑隐藏、上滑快速恢复底部播放器。

网站不提供“上传 PDF 后现场生成”的功能。

## 12. 验收门槛

批量系统至少满足：

- 所有发现的年度试卷都生成可追踪的 extraction 报告；
- 每篇只包含规定正文，不混入选择题选项或作文；
- 每句有中文对译；
- 词汇 1–9 级结构稳定，6–9 级可突出；
- 每句具有自然韵律导演信息；任意连续 3 句中至少有一个 `micro` 或 `strong` 节点；
- 主演员稳定，角色换声有文本依据；
- 音频路径静态可播放，失败片段不会拖垮整批；
- vivo/Android 浏览器继续可以直接打开同一 Pages 站点使用；
- 最终报告列出通过数、重试数、隔离失败数和待人工检查项。
